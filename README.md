# Crop Yield Prediction Using Machine Learning

## Overview

Crop Yield Prediction is a Machine Learning-based web application developed to predict agricultural crop yield using environmental and agricultural factors such as rainfall, temperature, pesticide usage, crop type, cultivation area, and year.

The system helps support data-driven agricultural decision-making by providing accurate crop yield predictions through a user-friendly web interface.

---

## Features

* Real-time crop yield prediction
* Machine Learning-based prediction engine
* Data preprocessing and feature engineering
* Model evaluation and comparison
* Flask API integration
* Interactive web interface

---

## Dataset Features

The model uses the following parameters:

* Area
* Crop Type
* Year
* Rainfall
* Pesticide Usage
* Temperature

to predict crop yield.

## Machine Learning Models
